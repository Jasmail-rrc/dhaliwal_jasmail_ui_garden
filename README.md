# Coding Assignment 13 – UI Component Library

## Student

Jasmail Singh Dhaliwal

## Description

This project demonstrates a React UI Component Library with code quality checks.

The project includes:

- Husky pre-commit hooks
- Prettier formatting checks
- ESLint checks
- Automated React tests
- GitHub Actions CI workflow
- Docker container running on localhost:8018

## Install

```bash
npm install
```

## Run locally

```bash
npm start
```

## Run quality checks

```bash
npm run quality
```

## Build Docker image

```bash
docker build -t dhaliwal_jasmail_coding_assignment13 .
```

## Run Docker container

```bash
docker run --name dhaliwal_jasmail_coding_assignment13 -p 8018:8018 dhaliwal_jasmail_coding_assignment13
```

Open:

http://localhost:8018
